como criar um novo metodo



fora do metodo main, fazemos algo assim:

    public static String greetUser(String firstName, String lastName) {
        return "Hello " + firstName + " " + lastName;
    }



public static ---- tipos do metodo - explicara melhor no futuro
String - o que a funcao retorna
greetUser --- nome do metodo
() - dentro do (), os parametros para a funcao. funcionam como variaveis
dentro da funcao main, chamamos greetUser, e passamos valores para os parametros

public class Main {

    public static void main (String [] args) {
        String msg = greetUser("Vinicius", "Trevisan");
        System.out.println(msg);
    }

    public static String greetUser(String firstName, String lastName) {
        return "Hello " + firstName + " " + lastName;
    }
}

como escolher o que refatorar?

1 - os conceitos ou as linhas de codigo que sempre estao juntos
2 - padroes repetitivos
